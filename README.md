# 模组简介

为少女前线2：追放的「危区探遗」提供第三人称越肩视角，兼容原生射击、开镜、方向回避、快捷栏投掷及界面。

当前版本 **0.53.0**。修正身后炸药箱等攻击标记错误显示到前方画面的问题：后方标记移出画布，转回面对目标时恢复。更换 DLL 需正常退出并重启游戏；本项实际游戏短测待确认。

## 使用

运行Start-GameAndMod.cmd

## 操作与功能

| 按键 | 操作                                    |
| ---- | --------------------------------------- |
| F7   | 原视角／越肩视角                        |
| F6   | 左右肩切换                              |
| F8   | 手动捕获／释放鼠标                      |
| F9   | 重读配置                                |
| F10  | 打开／关闭设置；可用 Esc 或关闭按钮关闭 |

- 鼠标控制水平与俯仰镜头，W 沿镜头前方移动，角色举枪跟随瞄准方向；WASD／斜向回避保持对应方向。
- 越肩相机距离、高度、偏移、FOV、平滑和灵敏度可调，支持相机墙面碰撞。
- 肩视角自动保留已识别的原生屋顶淡出组，F7 关闭恢复原生隐藏规则。
- 可扩大原生建筑加载范围，同时保持加载优先级、每次调度预算和卸载滞回。
- 屏幕中心瞄准；有效原生激光存在时使用来源校正，没有插件或未开镜时保持游戏参考点瞄准。
- 红点使用固定开镜视野，倍率红点自动使用 2 倍，精准瞄具自动使用 8 倍。放大动画与当前武器及配件的原生瞄准进度同步。
- 为越肩视角优化的UI显示设计，包括方向正确的声纹、动态血条、体力条等效果

## 源码构建

需要 MSVC x64、C++17 和 Windows SDK。在 x64 Visual Studio 开发者 PowerShell 中运行：

```powershell
.\Build.ps1
```
